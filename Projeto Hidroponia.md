# Projeto Hidroponia

## Descrição

Este projeto é uma página web educativa sobre **Hidroponia**, desenvolvida como atividade multidisciplinar que integra HTML, CSS e Git. A página apresenta informações completas sobre o sistema de cultivo hidropônico, seus benefícios, tipos de sistemas e dicas de manejo.

## Conteúdo

A página contém as seguintes seções:

- **O que é Hidroponia**: Definição e explicação do conceito fundamental
- **Benefícios Principais**: Economia de água, produtividade, controle nutricional e eficiência de espaço
- **Principais Tipos de Sistemas**: NFT, DFT, Sistema em Substrato e Aeroponia
- **Dicas Essenciais de Manejo**: Orientações práticas para o cultivo hidropônico

## Tecnologias Utilizadas

- **HTML5**: Estrutura semântica da página
- **CSS3**: Estilização responsiva e moderna
- **Git**: Controle de versão

## Estrutura do Projeto

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/hidroponia-projeto.git
```

2. Abra o arquivo `index.html` em seu navegador

## Recursos

- Design responsivo que se adapta a diferentes tamanhos de tela
- Navegação fixa para fácil acesso às seções
- Paleta de cores verde e azul que remetem ao tema de água e plantas
- Tipografia clara e legível com a fonte Poppins
